# 1x03 2.54mm Pitch Right-Angle SMD Pin Header

## Overview
- **Type**: 1x03 Right-Angle (Horizontal) SMD Pin Header
- **Pitch**: 2.54mm (0.1 inch)
- **Mounting**: Surface Mount (SMD / No Through-Hole drill)
- **Pad Type**: Rectangular SMD pads (3.0mm × 1.5mm)
- **Application**: ATtiny UPDI programming interface header (`J_UPDI1`)

## Pinout
- **Pin 1**: `+5V_LOCAL` / `+5V` Power Input
- **Pin 2**: `UPDI` Programming & Debug Data
- **Pin 3**: `GND` Ground
