# USB-C PD 12V Trigger / Decoy Module (IP2721)

## Overview
- **Module**: USB-C Power Delivery 12V Trigger / Decoy Module (Injoinic IP2721 / IP2721_PP27_30A)
- **Module Dimensions**: 16.3mm × 10.2mm (PCB), Total length ~20mm with overhanging USB-C port
- **Connector**: USB Type-C Female Receptacle (front edge)
- **Application**: Main power input module (`J_PWR1`) negotiating 12V DC from USB-C PD chargers for the system power tree

## Output Pinout (Rear Edge)
- **Pin 1 (Top Pair of Holes)**: `+12V_IN` (Positive 12V DC power output, dual 2.54mm holes joined by solder pad)
- **Pin 2 (Bottom Pair of Holes)**: `GND` (Ground return, dual 2.54mm holes joined by solder pad)
